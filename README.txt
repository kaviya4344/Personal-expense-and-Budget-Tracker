PERSONAL EXPENSE AND BUDGET TRACKER

Technology:
- Python
- Flask
- SQLite
- HTML
- CSS

How to run:
1. Open terminal in this project folder.
2. Install Flask:
   pip install -r requirements.txt
3. Run:
   python app.py
4. Open:
   http://127.0.0.1:5000

The expenses.db database is created automatically when the application starts.
